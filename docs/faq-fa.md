# FAQ، Known Issues و نکات ایمنی

## آیا WinUtil نصب دائمی می‌شود؟

خیر. ابزار در زمان اجرا دریافت و در حافظه اجرا می‌شود.

## آیا اینترنت لازم است؟

برای دریافت اولیه و نصب برنامه‌ها اینترنت لازم است. بسیاری از Tweaks پس از دریافت اسکریپت می‌توانند بدون اینترنت اجرا شوند، اما هر قابلیت وابسته به دانلود طبیعتاً به اتصال نیاز دارد.

## چرا آنتی‌ویروس هشدار می‌دهد؟

WinUtil تغییرات سطح سیستم انجام می‌دهد و ممکن است برخی رفتارهای آن برای محصولات امنیتی حساس باشد. منبع را بررسی کنید و فقط از نسخه رسمی استفاده کنید؛ برای اجرای اسکریپت ناشناس، آنتی‌ویروس را کورکورانه غیرفعال نکنید.

## خطای Constrained Language Mode

PowerShell در Constrained Language Mode ممکن است اجرای WinUtil را مسدود کند. در محیط‌های سازمانی، قبل از تغییر Policyهای امنیتی باید علت فعال‌بودن این حالت مشخص شود.

## خطای `download < : The term '<' is not recognized...`

این خطا در مستندات Known Issues آمده و ممکن است با VPN یا شرایط دریافت اسکریپت مرتبط باشد. منبع رسمی و وضعیت اتصال را بررسی کنید.

## Ultimate Performance روی لپ‌تاپ

ممکن است Ultimate Performance روی بعضی لپ‌تاپ‌ها پشتیبانی نشود یا مزیت محسوسی نداشته باشد.

## Start Menu Previous Layout کار نمی‌کند

طبق Known Issues فعلی، از Windows 11 KB5089573 در May 2026 کد قدیمی لازم برای این قابلیت توسط Microsoft حذف شده و این Tweak دیگر مانند گذشته کار نمی‌کند.

## PowerShell 7 و خطای DISM

نسخه Microsoft Store که به‌صورت MSIX نصب می‌شود ممکن است باعث خطای `Class not registered` در DISM شود. راهکار پیشنهادی استفاده از نصب‌کننده WinGet/Wix یا MSI رسمی است، برای مثال:

```powershell
winget install --id Microsoft.PowerShell --source winget --installer-type wix
```

## اگر یک Tweak را اشتباه فعال کردم چه کنم؟

در صورت وجود Undo برای همان Tweak، دوباره آن Tweak را انتخاب و Undo Selected Tweaks را اجرا کنید. برای تغییرات مهم، System Restore یا Backup را در اولویت قرار دهید.

## آیا Essential همیشه امن است؟

Essential نسبت به Advanced محافظه‌کارانه‌تر است، اما «مناسب برای همه سیستم‌ها» به معنای «بدون هیچ اثر جانبی» نیست. مثلاً تغییر Services، BitLocker، Location یا Hibernation می‌تواند روی نیازهای خاص شما اثر بگذارد.

## آیا Windows Update را خاموش کنم؟

برای استفاده روزمره توصیه نمی‌شود. اگر هدف کنترل Restart یا تأخیر Update است، Recommended معمولاً انتخاب منطقی‌تری است.

## آیا WinUtil خودش اطلاعات کاربر را ارسال می‌کند؟

طبق FAQ پروژه، WinUtil به‌خودی‌خود داده کاربر را جمع‌آوری و ارسال نمی‌کند؛ با این حال برنامه‌ها، سرویس‌ها و ابزارهای ثالثی که کاربر نصب یا اجرا می‌کند ممکن است سیاست‌های داده‌ای مستقل داشته باشند.

## برای Gaming چه تنظیمی مناسب است؟

راهنمای پروژه پیشنهادهایی مانند Desktop preset، Disable GameDVR، Ultimate Performance و برخی performance tweaks را مطرح می‌کند؛ اما هیچ Tweak تضمین نمی‌کند که FPS همیشه افزایش پیدا کند. عملکرد به CPU، GPU، RAM، درایور، بازی و تنظیمات آن وابسته است.

## RAM مصرفی WinUtil چقدر است؟

FAQ پروژه مصرف حدود 50 تا 100MB هنگام اجرا را ذکر می‌کند.

## Access Denied

ابتدا Administrator بودن Terminal را بررسی کنید. سپس Antivirus/EDR، مالکیت فایل‌ها و محدودیت‌های سازمانی را بررسی کنید.

## توصیه نهایی

قبل از تغییرات گسترده: Restore Point، Backup، ثبت تنظیمات فعلی و اجرای مرحله‌ای را در نظر بگیرید. برای سیستم اصلی، ابتدا تغییرات کم‌ریسک‌تر را آزمایش کنید و بعد سراغ Advanced بروید.
