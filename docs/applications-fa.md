# Applications — مدیریت برنامه‌ها

## منبع نصب

WinUtil برای مدیریت برنامه‌ها از package managerهایی مانند WinGet و Chocolatey استفاده می‌کند. بنابراین نام، نسخه و وضعیت نصب ممکن است به مخزن بسته و شرایط سیستم وابسته باشد.

## Install

برنامه موردنظر را انتخاب کنید و Install را اجرا کنید. قبل از نصب، نام ناشر و منبع بسته را بررسی کنید؛ مخصوصاً برای نرم‌افزارهای حساس.

## Upgrade

برای به‌روزرسانی برنامه انتخاب‌شده استفاده می‌شود. اگر برنامه‌ای خارج از manager نصب شده باشد، ممکن است توسط WinUtil مدیریت نشود.

## Upgrade All

برای تلاش جهت به‌روزرسانی همه برنامه‌های قابل مدیریت استفاده می‌شود. در سیستم کاری، بهتر است قبل از اجرای آن از برنامه‌های در حال اجرا و نسخه‌های فعلی آگاه باشید.

## Uninstall

برنامه انتخاب‌شده را حذف می‌کند. حذف یک برنامه لزوماً تمام داده‌های کاربر یا تنظیمات آن را پاک نمی‌کند.

## Search

برای یافتن packageهای موجود استفاده می‌شود. اگر چند نتیجه با نام مشابه دیدید، ناشر و شناسه package را بررسی کنید.

## Installed

فهرست برنامه‌های نصب‌شده/قابل شناسایی توسط manager را بررسی کنید.

## نکات عیب‌یابی

اگر WinGet مشکل دارد، از Config > Fixes > WinGet Reinstall استفاده کنید. اگر Store یا شبکه مشکل دارد، ابتدا همان مشکل پایه را برطرف کنید؛ اجرای Upgrade All مشکل شبکه را حل نمی‌کند.

## پیشنهاد برای سیستم اصلی

برنامه‌های ضروری را یکی‌یکی نصب/Upgrade کنید. برای تعداد زیاد نرم‌افزار، قبل از Upgrade All یک Restore Point یا حداقل Backup از داده‌های مهم داشته باشید.
