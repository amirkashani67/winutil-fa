# Win11 Creator — راهنمای فارسی

Win11 Creator برای ساخت یک Windows 11 سفارشی از ISO رسمی استفاده می‌شود.

## الزامات

- ISO رسمی Windows 11
- حداقل حدود 4GB فضای لازم برای کار ابزار و حدود 10 تا 15GB فضای موقت توصیه‌شده
- اجرای WinUtil با Administrator
- استفاده از ISO سفارشی/غیراصلی پشتیبانی نمی‌شود.

## نکات حیاتی

این فرآیند برای **Fresh/Clean Install** است و جایگزین In-place Upgrade نیست. قبل از ساخت USB یا نصب، از فایل‌های مهم Backup بگیرید.

## مراحل کلی

1. WinUtil را با Administrator اجرا کنید.
2. Win11 Creator را باز کنید.
3. ISO رسمی را انتخاب/بررسی کنید.
4. ابزار وجود `install.wim` یا `install.esd` را بررسی می‌کند.
5. Edition موردنظر را انتخاب کنید؛ Pro در صورت موجودبودن گزینه پیش‌فرض است.
6. تغییرات سفارشی‌سازی را انتخاب کنید.
7. در صورت نیاز Driverها را Inject کنید.
8. ISO خروجی بسازید یا مستقیماً USB را آماده کنید.

## تغییرات مهم Creator

طبق مستندات فعلی، Creator بیش از 40 برنامه/اجزای bloat را حذف می‌کند، تنظیم OneDrive را تغییر می‌دهد، برخی بررسی‌های TPM/Secure Boot/CPU/RAM/Storage را دور می‌زند، Local Account را از طریق autounattend فعال می‌کند، BitLocker/Device Encryption را غیرفعال می‌کند، Chat icon را کنترل می‌کند، Edition را pin می‌کند و تنظیمات privacy/telemetry را تغییر می‌دهد.

Windows Update در OOBE موقتاً غیرفعال و بعد از اولین ورود دوباره فعال می‌شود.

## ساخت ISO

برای Export ISO به `oscdimg.exe` نیاز است. در مستندات WinUtil پیشنهاد شده در صورت نیاز:

```powershell
winget install -e --id Microsoft.OSCDIMG
```

## ساخت USB مستقیم

اگر گزینه ساخت مستقیم USB را انتخاب می‌کنید، محتوای درایو هدف پاک می‌شود. طبق مستندات، USB با GPT و EFI حدود 512MB آماده می‌شود و حداقل 8GB توصیه شده است. عملیات بسته به سیستم حدود 10 تا 20 دقیقه ممکن است طول بکشد.

## هشدار

Bypass کردن الزامات سخت‌افزاری ممکن است نصب Windows را روی سیستم ناسازگار ممکن کند، اما تضمین نمی‌کند که همه Updateها یا قابلیت‌ها در آینده بدون مشکل کار کنند. این گزینه را فقط با آگاهی از محدودیت‌های سخت‌افزار استفاده کنید.
