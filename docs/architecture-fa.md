# ساختار فنی WinUtil

این صفحه برای کسانی است که می‌خواهند بدانند WinUtil چگونه سازمان‌دهی شده است.

## فایل‌های Config

- `config/applications.json`: تعریف برنامه‌ها و packageها
- `config/tweaks.json`: تعریف Tweaks، توضیحات و اطلاعات Undo
- `config/feature.json`: Windows Features
- `config/preset.json`: ترکیب چند Tweak در Preset
- `config/dns.json`: گزینه‌های DNS

## کد اجرایی

- `functions/public`: توابعی که از بخش‌های مختلف رابط/اسکریپت فراخوانی می‌شوند.
- `functions/private`: توابع داخلی و کمکی.
- `scripts`: اسکریپت‌های جانبی.
- `xaml`: اجزای رابط کاربری.
- `Compile.ps1`: فرآیند Build/تولید خروجی.

## مدل Tweak

هر Tweak در Config تعریف می‌شود و منطق اجرای آن به توابع پروژه متصل است. برای تغییرات قابل بازگشت، اطلاعات Undo نیز در تعریف Tweak در نظر گرفته می‌شود.

به همین دلیل، وقتی یک کلید Tweak در نسخه جدید حذف یا تغییر کند، فایل Preset یا Export قدیمی ممکن است دیگر با نسخه جدید سازگار نباشد.

## توسعه

اگر قصد توسعه دارید، قبل از تغییر Configها باید ساختار JSON، نام کلیدهای انتخاب، مسیر توابع و منطق Undo را بررسی کنید. برای تغییرات بزرگ بهتر است ابتدا در Branch جداگانه کار و سپس Pull Request ایجاد شود.
