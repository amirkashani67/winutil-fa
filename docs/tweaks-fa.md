# Tweaks — راهنمای فارسی

این صفحه مهم‌ترین گزینه‌های Tweaks فعلی WinUtil را به زبان ساده توضیح می‌دهد.

## Presetها

### Standard

برای بیشتر کاربران مناسب‌تر است. مجموعه‌ای از Activity History، Consumer Features، Auto Discovery فایل‌ها، WPBT، Location، Services، Telemetry، Delivery Optimization، پاک‌سازی فایل‌های موقت، Disk Cleanup، End Task از Taskbar و ایجاد Restore Point را اعمال می‌کند.

### Minimal

تغییرات محدودتر: Consumer Features، WPBT، Services و Telemetry.

### Advanced

مجموعه گسترده‌تری شامل موارد بالا، Store Search، Start Menu قدیمی، Widgets، OneDrive، Windows AI و Right-Click Menu را نیز تغییر می‌دهد.

## Customize Preferences

- System Tray Battery Percentage: نمایش درصد باتری در System Tray.
- Start Menu Bing Search: کنترل جست‌وجوی Bing در Start.
- Dark Theme for Windows: فعال‌کردن تم تاریک.
- BSoD Verbose Mode: نمایش جزئیات بیشتر هنگام خطای صفحه آبی.
- Lock Screen - Disable: غیرفعال‌کردن Lock Screen.
- Game Mode: فعال/غیرفعال‌کردن Game Mode.
- File Explorer Hidden Files: نمایش فایل‌های مخفی.
- Settings Home Page: کنترل صفحه Home تنظیمات.
- Logon Screen Acrylic Blur: کنترل افکت Acrylic در صفحه ورود.
- Enable Long Paths: فعال‌کردن مسیرهای طولانی.
- Mouse Acceleration: کنترل شتاب موس.
- Multiplane Overlay: کنترل MPO؛ در عیب‌یابی برخی مشکلات گرافیکی کاربرد دارد.
- Microsoft Outlook New Version: کنترل نسخه جدید Outlook.
- Num Lock on Startup: فعال‌بودن Num Lock هنگام شروع.
- S3 Sleep: تلاش برای فعال‌سازی حالت Sleep نوع S3 در سیستم‌های سازگار.
- Scrollbars Always Visible: همیشه قابل مشاهده بودن Scrollbar.
- File Explorer File Extensions: نمایش پسوند فایل‌ها.
- S0 Sleep Network Connectivity: کنترل اتصال شبکه در Modern Standby/S0.
- Start Menu Recommendations: کنترل Recommendations در Start.
- Sticky Keys: کنترل Sticky Keys.
- Taskbar Centered Icons: وسط‌چین یا تغییر وضعیت آیکون‌های Taskbar.
- Taskbar Search Icon: کنترل آیکون Search.
- Taskbar Task View Icon: کنترل Task View.
- Logon Verbose Mode: نمایش جزئیات بیشتر هنگام ورود.
- Window Snapping: کنترل قابلیت Snap پنجره‌ها.

## Essential

- Activity History - Disable: غیرفعال‌کردن Activity History.
- ConsumerFeatures - Disable: جلوگیری از برخی نصب‌ها/پیشنهادهای مصرف‌کننده.
- Temporary Files - Remove: حذف فایل‌های موقت.
- Delivery Optimization - Disable: غیرفعال‌کردن Delivery Optimization.
- BitLocker - Disable: کنترل/غیرفعال‌سازی BitLocker؛ روی سیستم رمزگذاری‌شده با احتیاط.
- File Explorer Automatic Folder Discovery - Disable: جلوگیری از تشخیص خودکار نوع پوشه.
- Microsoft Store Recommended Search Results - Disable: حذف نتایج پیشنهادی Store از جست‌وجو.
- Disk Cleanup - Run: اجرای Disk Cleanup.
- End Task With Right Click - Enable: افزودن End Task به منوی راست‌کلیک Taskbar.
- Hibernation - Disable: حذف/غیرفعال‌کردن Hibernation و فایل مربوطه.
- Location Tracking - Disable: غیرفعال‌کردن Location Tracking.
- Prevent Device Companion Apps: جلوگیری از برخی Companion Appهای خودکار.
- Restore Point - Create: ایجاد System Restore Point.
- Start Menu Previous Layout - Enable: تلاش برای بازگرداندن Layout قدیمی Start؛ در نسخه‌های جدید ممکن است دیگر کار نکند.
- Services - Set to Manual: تنظیم سرویس‌های منتخب روی Manual؛ اثر این گزینه را قبل از اجرا بررسی کنید.
- Telemetry - Disable: کاهش/غیرفعال‌کردن Telemetry و برخی داده‌های تشخیصی.
- Widgets - Remove: حذف Widgets.
- WPBT - Disable: غیرفعال‌کردن Windows Platform Binary Table.

## Advanced

- Adobe URL Block List: مسدودکردن URLهای مشخص Adobe.
- Brave Browser - Debloat: حذف/کاهش اجزای غیرضروری Brave.
- DNS - Set to: تنظیم DNS.
- Background Apps - Disable: محدودکردن اجرای برنامه‌ها در پس‌زمینه.
- IPv6 - Disable: غیرفعال‌کردن IPv6؛ فقط در صورت نیاز واقعی.
- System Tray Notifications & Calendar - Disable: کاهش اعلان‌ها/Calendar در System Tray.
- RDP Unsigned File Warnings - Disable: تغییر هشدار فایل‌های unsigned در RDP.
- Visual Effects - Best Performance: کاهش جلوه‌های بصری برای عملکرد.
- Microsoft Edge - Debloat: حذف برخی اجزای غیرضروری Edge.
- IPv6 - Set IPv4 as Preferred: ترجیح IPv4 بدون لزوماً حذف IPv6.
- O&O ShutUp10++: اجرای ابزار تنظیم حریم خصوصی.
- Razer Software Auto-Install - Disable: جلوگیری از نصب خودکار نرم‌افزار Razer.
- Microsoft Edge - Remove: حذف Edge؛ گزینه‌ای تهاجمی‌تر و دارای تبعات احتمالی.
- File Explorer Home and Gallery - Disable: کنترل Home و Gallery.
- Microsoft OneDrive - Remove: حذف OneDrive.
- Disable Reserved Storage: غیرفعال‌کردن Reserved Storage.
- Right-Click Menu Previous Layout - Enable: تلاش برای منوی راست‌کلیک قدیمی.
- Storage Sense - Disable: غیرفعال‌کردن Storage Sense.
- Teredo - Disable: غیرفعال‌کردن Teredo؛ ممکن است روی برخی قابلیت‌های شبکه/بازی اثر بگذارد.
- Date & Time - Set Time to UTC: تنظیم زمان سیستم روی UTC؛ برای اکثر کاربران دسکتاپ انتخاب مناسبی نیست مگر سناریوی خاص.
- Windows AI - Disable And Remove: غیرفعال‌کردن و حذف اجزای Windows AI.

## توصیه عملی

برای شروع، Restore Point بسازید و سپس فقط گزینه‌های موردنیاز را فعال کنید. «Advanced» را به‌صورت یک بسته کور اجرا نکنید؛ چون ممکن است قابلیت‌هایی که واقعاً به آن‌ها نیاز دارید، تغییر یا حذف شوند.
